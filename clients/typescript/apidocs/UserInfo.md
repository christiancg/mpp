# UserInfo

One user, as `Users.list` returns it.

## username

The username.

## admin

Whether the user is an admin.

## globalPermissions

Server-wide grants.

## projectPermissions

Grants by project.

## collectionPermissions

Grants by `project|collection`.

## scriptPermissions

Script grants by project.

## ownedProjects

The projects the user owns.

## raw

The row as the server sent it.
